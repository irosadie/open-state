## Purpose

Provides type-safe PostgreSQL access via sqlc-generated query code and schema migration management via goose, replacing Prisma.

## ADDED Requirements

### Requirement: Migrations managed by goose
The system SHALL use goose to manage all database schema migrations. Migration files MUST be sequential SQL files stored in `apps/api/db/migrations/`.

#### Scenario: Migration runs successfully
- **WHEN** `goose up` is run against a PostgreSQL database
- **THEN** all pending migrations SHALL be applied in order

#### Scenario: Migration is idempotent
- **WHEN** `goose up` is run on an already-migrated database
- **THEN** no migration SHALL be applied twice

### Requirement: Queries generated by sqlc
The system SHALL use sqlc to generate type-safe Go code from SQL query files in `apps/api/db/queries/`. Generated code MUST NOT be edited manually.

#### Scenario: Query returns typed result
- **WHEN** a sqlc-generated query function is called with valid parameters
- **THEN** it SHALL return a Go struct matching the column types of the result set

#### Scenario: sqlc regenerated after query change
- **WHEN** a `.sql` query file is modified
- **THEN** running `sqlc generate` SHALL regenerate the corresponding Go code

### Requirement: Database connection uses pgx
The system SHALL connect to PostgreSQL using `jackc/pgx/v5` as the driver. Connection string MUST be read from environment variable `DATABASE_URL`.

#### Scenario: Successful connection
- **WHEN** `DATABASE_URL` is set to a valid PostgreSQL connection string
- **THEN** the application SHALL establish a connection pool on startup

#### Scenario: Missing DATABASE_URL fails fast
- **WHEN** `DATABASE_URL` is not set
- **THEN** the application SHALL exit at startup with a clear error message
